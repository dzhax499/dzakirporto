# Pembaruan dokumentasi OCR WhatsApp

Lima screenshot asli di `img/projek/ocr-wa/` dipertahankan tanpa modifikasi:

- `3.jpg`, `4.jpg`, `5.jpg`: pemilihan program, kode relawan, dan order menunggu
  konfirmasi mutasi bank.
- `1.jpg`, `2.jpg`: program/nama dari caption, kode relawan, dan respons duplikat.

Galeri dipisah per percakapan, mempertahankan urutan scroll di tiap kelompok.
Setiap gambar ditampilkan utuh dan bisa dibuka ukuran asli melalui link.
Thumbnail memakai `5.jpg`; bagian hasil chat difokuskan menggunakan CSS, tanpa
mengubah file asli. Preview dan halaman detail tetap menggunakan file utuh.
`full-workflow.png` tetap tampil sebagai dokumentasi workflow. `thumbnail.png`
lama tetap disimpan; pembersihan aset pada tugas ini hanya menyasar CashFlow.

Deskripsi ID/EN diperbarui berdasarkan README, docs/01-overview.md,
ocr-api/requirements.txt, dan pembacaan deklarasi fungsi/import pada main.py,
ocr_engine.py, dan database.py dari proyek OCR lokal (15 Oktober 2026).
Tidak menjalankan layanan, membaca `.env`, atau menghubungi WhatsApp, Supabase,
Moota, maupun API platform donasi.

Hasil chat tidak diklaim sebagai konfirmasi dana diterima: screenshot terakhir
menyatakan masih menunggu mutasi bank. Keterangan rekonstruksi/tidak tersedianya
screenshot pada dokumentasi lama sudah dihapus karena kini tersedia gambar asli.
Foto tetap mengandung nama, kode relawan, serta referensi order yang terlihat
pada materi dari pemilik; periksa izin materi sebelum publikasi.
